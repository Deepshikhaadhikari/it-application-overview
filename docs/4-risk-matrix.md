# Risk Matrix

## Biggest Risk
My biggest risk is Cloud Synchronization.

## The Problem
If sync does not work, users will lose their notes. Or they will see old notes on their phone. This is bad. Also, if many users use the app at same time, the database can be slow.

## Backup Plan
If the first plan fails, I will do this:
1. Use a simple save button first. Notes will save when user clicks save.
2. Use local data first. Save notes in a JSON file, not live cloud.
3. Add cloud sync later after testing.
