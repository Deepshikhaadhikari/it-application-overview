# Tech Stack

## What I Will Use

* React - For the front-end. It makes the pages and buttons.
* Firebase - For login and database. It saves user data.
* Tailwind CSS - For design. It makes the app look clean.
* JavaScript - For the logic. Like making tasks and saving notes.

## Hosting
I will host on Vercel. Vercel is free for students and easy to use. I can put my code on GitHub, and Vercel will make a live link. If Vercel does not work, I will use Firebase Hosting as backup.
