# MVP Scope

## My App
My app is Notion. Notion helps students write notes, make tasks, and stay organized. It is one place for school work.

## Launch Goal
My goal is to launch v1.0 by December 15, 2025.

## Must Have - For MVP

1. Page Creation / Notes
This is important. Users need to make pages and write notes. Without this, the app has no use.

2. Task / To-Do Management
Users can make tasks and check them when done. This helps students finish homework on time.

3. Cloud Synchronization
Notes save in the cloud. Users can open notes on phone or laptop. This is good because notes will not be lost.

## Nice to Have - Later

1. Real-time Collaboration
This is good but hard. For v1.0, users can just share a link. We can add live editing later.

2. Databases / Templates
This is also good but takes time. For v1.0, simple pages are enough. We can add this in v2.0.
